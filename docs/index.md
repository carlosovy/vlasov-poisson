
# Vlasov-Poisson

A Python solver for the one-dimensional Vlasov-Poisson system
using semi-Lagrangian methods and Strang splitting.

## Overview

The solver supports:

- Landau damping simulations.
- Bump-on-tail instability simulations.
- Linear and cubic spline interpolation.
- Diagnostics for electric-field evolution, particle number,
  and total energy.
